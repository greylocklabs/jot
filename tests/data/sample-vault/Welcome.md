Notes are plain Markdown files in this folder. Folders are notebooks.
The Syntax guide, in the help menu, shows what Jot reads in them.

Links between notes are plain Markdown, so they work in any editor. Type `](` after a link's
words, or press Ctrl+K, to pick a note: [the pitch](Ashfall/Pitch.md). Copy link writes one from
the top of the vault, which works from any notebook: [Mara Vey](/Ashfall/Characters/Mara%20Vey.md).
A link to a note not written yet makes it when you follow it: [a new idea](Ideas/Someday.md).
